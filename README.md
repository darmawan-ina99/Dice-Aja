# 🎲 Dadu Aja

Versi web dari game dadu "The Dice" (net.dzyga.android.thedice) dengan dua peningkatan:

1. **Durasi lempar bisa diatur** - Cepat (2 detik), Normal (4 detik), Santai (6,5 detik). Dadu berhenti bergantian satu per satu biar seru.
2. **Mode Prediksi** - tekan lama judul "DADU AJA" untuk mengaktifkan mata 👁. Angka dadu lemparan BERIKUTNYA bisa dilihat sebelum melempar (mode stealth buat pamer ke teman).

Plus: jumlah dadu 1-6, riwayat lemparan, efek suara, dan pengaturan tersimpan otomatis.

Demo: https://darmawan-ina99.github.io/Dice-Aja/
